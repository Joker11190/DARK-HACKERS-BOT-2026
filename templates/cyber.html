🛡️ مقدمة الأمن السيبراني

MODULE 02

🎣 التصيد الإلكتروني PHISHING

من أشهر طرق خداع المستخدمين على الإنترنت.

افتح الشرح الكامل
التصيد الإلكتروني بيحصل لما شخص يستخدم رسالة أو صفحة مزيفة علشان يخدعك وتكشف بياناتك.

علامات الخطر: رابط غريب، استعجال غير طبيعي، طلب كلمة المرور أو كود التحقق.

الحماية: متضغطش على الروابط المشبوهة، وافتح الموقع الرسمي بنفسك.
MODULE 03

🦠 البرمجيات الخبيثة MALWARE

فهم البرامج الضارة وتأثيرها على الأجهزة والملفات.

افتح الشرح الكامل
Malware اسم عام للبرمجيات المصممة لتنفيذ أنشطة ضارة.

من أنواعها:
• Virus: فيروس يرتبط بملفات أو برامج.
• Trojan: برنامج يتظاهر بأنه مفيد.
• Ransomware: برمجية تشفر الملفات وتطلب فدية.

الوقاية: حمّل البرامج من مصادر موثوقة، وحدّث جهازك، وتجنب الملفات المجهولة.
MODULE 04

🌐 NETWORK SECURITY

حماية الشبكات والاتصالات من المخاطر.

افتح الشرح الكامل
أمن الشبكات هو حماية البنية الشبكية والبيانات المتبادلة بين الأجهزة.

من أساسيات الحماية:
• استخدام تشفير Wi-Fi قوي.
• تغيير كلمة مرور الراوتر الافتراضية.
• تحديث البرامج الثابتة للراوتر.
• استخدام جدار الحماية Firewall.

ونتعلم اختبار الشبكات داخل بيئات نمتلكها أو لدينا تصريح بفحصها.
MODULE 05

🔐 PASSWORD SECURITY

إزاي نعمل كلمات مرور صعبة التخمين ونحمي حساباتنا.

افتح الشرح الكامل
كلمة المرور القوية تكون طويلة وفريدة لكل حساب، ويفضل استخدام مدير كلمات مرور.

فعّل المصادقة الثنائية 2FA، ومتشاركش رموز التحقق مع أي شخص.

💀 TERMUX ACADEMY

أكاديمية DARK HACKERS التعليمية

أهلاً يا شباب DARK HACKERS ❤️

النهارده هنبدأ أول خطوة لينا في عالم Termux. أنا هشرحلكم من الصفر، وهنطبق مع بعض خطوة بخطوة.

يعني إيه Termux؟

هو تطبيق بيوفر بيئة أوامر شبيهة بلينكس على أندرويد، ونقدر نتعلم من خلاله البرمجة وإدارة الملفات.

أول تطبيق عملي:

pkg update
pkg upgrade -y

الأوامر دي بتحدّث قوائم الحزم والبرامج المثبتة.

يا شباب، النهارده هنتعلم أهم الأوامر.

pwd
ls
whoami
date
clear
  • pwd: معرفة مكاننا الحالي.
  • ls: عرض الملفات.
  • whoami: معرفة اسم المستخدم.
  • date: عرض التاريخ والوقت.
  • clear: تنظيف الشاشة.

النهارده هنعمل أول مشروع بإيدينا.

mkdir MyProject
cd MyProject
touch first.txt
echo "Welcome to DARK HACKERS" > first.txt
cat first.txt
ls

كده أنشأنا مجلد وملف وكتبنا فيه رسالة وعرضنا محتواه.

هنبدأ نتعلم تثبيت الأدوات.

pkg update
pkg install python -y
pkg install git -y
python --version
git --version

ثبتنا Python وGit وتأكدنا من وجودهما.

أول كود Python لينا!

python
print("DARK HACKERS")
print(10 + 20)
exit()

الأمر print بيعرض النصوص والنتائج على الشاشة.

إدارة المشاريع البرمجية

git --version
git init
git status

Git بيساعدنا نتابع تغييرات ملفات المشروع وننظم شغلنا.

نفهم الشبكات من البداية.

pkg install dnsutils -y
nslookup example.com

هنا بنتعلم الاستعلام عن معلومات DNS لنطاق تجريبي.

الحماية أهم من الاختراق.

  • اختيار كلمات مرور قوية.
  • تفعيل المصادقة الثنائية.
  • تحديث التطبيقات.
  • التدرب داخل بيئات قانونية ومصرح بها.
